# Laser Defender

A classic 2D vertical scrolling space shooter game created in Unity.

## 🎮 Overview
- **Engine**: Unity (URP - Universal Render Pipeline)
- **Genre**: 2D
- **Language**: C#

## 🚀 Getting Started
1. Clone the repository:
   ``bash
   git clone https://github.com/hamzadeveloper-07/Laser-Defender.git
   ``
2. Open **Unity Hub**.
3. Click **Add** and select this project directory.
4. Open the project with Unity 6 / Unity 2022+ (Universal Render Pipeline).

## 📁 Project Structure
- Assets/ - Game scripts, sprites, audio, animations, and prefabs.
- Packages/ - Unity package manifests and dependencies.
- ProjectSettings/ - Input, physics, tags, layers, and engine configurations.
